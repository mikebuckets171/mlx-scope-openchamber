# Historical plans, designs and evidence

These documents describe earlier releases. They are preserved as evidence, not instructions for the current product.
Paths, version claims, screenshots and outstanding-work notes inside them refer to their original release. In
particular, receipts remain byte-for-byte unchanged; their old paths and measurements are not current claims.

- `2.0/`, `3.0/`, `3.1/`: release plans, qualification and migration records.
- `design/`: prior mockups, design decisions and screenshots. The synthetic v2 corpus is still used by tests.
- `receipts/`: historical overhead and companion-compatibility measurements, including the 4.0 verification report.

Current product documentation is in `docs/*.md`; current screenshots are in `docs/assets/`.
