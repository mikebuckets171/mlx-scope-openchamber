# Scope 4 panel inventory

This inventory covers the existing synthetic fixture UI and the run inspector. Its purpose is to preserve the current navigation and measured facts while making every surface consistent, readable and naturally sized.

## Shared hierarchy

| Role | Existing surfaces | Rule |
| --- | --- | --- |
| Current activity | Session, compact, Live | Phase, one primary reading, available supporting facts, then detail/actions. |
| Section heading | Server, History, Captures, Media, Connections | A heading remains larger than its explanatory text as host text size changes. |
| Supporting copy | Provenance, empty states, setup guidance, progress detail | Share caption/detail roles; wrap within the surface and retain meaningful separation. |
| Actions and disclosures | Every surface | Share control sizing and typography. Labels may wrap; targets remain at least 24 px and keyboard focus survives updates. |
| Empty regions | Readout parts, rows, plots, optional actions | Omit absent content or use its natural zero height. A useful explanation has natural height, without a placeholder-sized frame. |
| Run details | Current observation, recorded turn, recorded reply, comparison | Reuse the section, fact-list and action roles. Keep measurement basis beside its value and comparison grouping on a separate readable line. |

The stylesheet defines shared caption, detail, body, heading and title roles. Each preserves its ordinary minimum size and grows with the host's root text size. Shared content and section spacing remain fixed design intervals; increasing text can add lines without magnifying blank reserves.

## Material findings

1. The earlier empty-state pass removed wholly empty hero, glance, usage and setup regions. A populated hero still reserved 80/96 px by default, and narrow evidence reserved 11.25 rem. At enlarged text this could leave about 200 px after two measured facts. Readout parts now take their content's height; an entirely quiet readout still removes its outer margins.
2. Explanations already scaled with host text size, but many section headings, controls and media labels used fixed pixel fonts. At a 32 px root, a 22 px explanation could sit beneath a 13–14 px heading and beside a 12 px button. Shared text roles preserve the hierarchy as the user enlarges text.
3. Scaling control text exposes fixed-height select controls and long unwrapped action labels. Select heights scale with text (including native WebKit controls), and labels wrap within the surface. Media progress reserves a readable text column and places an action on another line when necessary. Mac and metric groups reduce columns as text grows, preserving the complete values.

No reading, state or setup instruction is removed. No new collection, timer, dependency or permission is introduced.

## Geometry and interaction coverage

The canonical mock-state inventory drives the geometry sweep, so a new state joins the suite automatically. Every applicable state visits Live, Media, Server, History, Captures, Connections and compact mode across these profiles:

| --- | --- | --- | --- |

| Page | 1,160 px | 16 px | Light |
| Panel | 430 px | 24 px | Light |
| Panel | 320 px | 32 px | Dark |
| Page | 1,160 px | 32 px | Dark |
| Session | 280 px | 16 px | Dark |
| Session | 280 px | 32 px | Light |

The matrix is finite cross-surface coverage, not every possible combination. Additional focused checks cover both themes at narrow, rail and wide sizes; populated and empty secondary views; current and recorded run details; controls, focus return and disclosures; and unchanged structure during same-state measurement updates. Entering a secondary view keeps its heading and return control in the viewport, including after leaving a long enlarged Live view. The existing motion suite remains responsible for animation, hidden surfaces and reduced motion.

Assertions count outer margins as occupied space, reject horizontal overflow, and require each readout part to fit its visible children rather than a fixed reserved height. They preserve explanations and genuine spacing. Real content changes may move later sections; routine polls must preserve focus, disclosure state and same-state geometry.

Visual review includes ordinary and enlarged text, active media and setup guidance. Screenshots and detailed fixture logs remain outside the repository. These checks establish synthetic rendering behavior, not native OpenChamber rendering or live-runtime telemetry correctness.
