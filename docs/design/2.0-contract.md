# MLX Scope 2.0 · wire contract v2

Design contract for the G2 gate. Stage 2a implements it in `src/contract/*` and the service routes. It follows plan §4.2.
Where the plan and `docs/2.0/SPIKES.md` differ, the G1 amendments in SPIKES win. Every change from plan §4.2 is listed in
[§10](#10-changes-from-plan-42-for-owner-review).

The mock (`docs/design/2.0-mock.html`) renders only data that fits these types. Its fixtures
(`docs/design/2.0-mock-fixtures.json`) are synthetic `SnapshotV2`, `TrendV2` and `UsageV2` bodies.
`node docs/design/shoot-2.0-mock.mjs --check-only` checks them against this document: required fields, integer `*Bytes`,
`*Fraction` ranges, the honesty invariant, the route size limit and the absence of class A keys.

## 1. Transport rules

- **GET only.** Any other method returns `405` (the guard at `service/server.ts:22` stays).
- **Bearer auth.** `Authorization: Bearer <OPENCHAMBER_SERVICE_TOKEN>`, compared in constant time. Missing or wrong → `401`.
- **Headers.** `Cache-Control: no-store`, `Content-Type: application/json; charset=utf-8`.
- **Size.** Every response body is asserted **< 256,000 characters** (the SDK response limit). A test fills every `/v2/*`
  route to its caps and checks this.
- **Parsing in frames.** `serviceRequest` returns `body` as a **string** (SPIKES S1). Frames `JSON.parse` it, then validate
  it with `parseSnapshotV2` / `parseTrendV2` / `parseUsageV2` before any value reaches the DOM.
- **No push.** There is no service→frame channel. Frames poll at `nextPollMs`.

## 2. Routes

| Route | Purpose | Response |
|---|---|---|
| `/health` | Liveness. Unchanged from 1.6. | `{ ok: true, version }` |
| `/v2/snapshot?provider&runtime&frame&surface&tier&since&mark&attr&detail` | The main poll. | `SnapshotV2` |
| `/v2/trend?provider&runtime&window=900\|1800\|3600&series=` | History chart. ≤180 buckets of `[min, max, last]`, plus `gaps[]` and `marks[]`. | `TrendV2` |
| `/v2/usage?provider&range=7d\|30d\|90d` | oMLX `/admin/api/usage` read-through. 5 min cache, allowlisted fields. | `UsageV2` |
| `/snapshot` | Retired 1.x route. | **`410`** `{ error: 'contract_mismatch', contractVersion: 2 }` |

Other paths → `404 { error: 'not_found' }`. Bad parameters → `400 { error: 'bad_query', param }`.

**Version skew.** A 1.6 panel talking to a 2.0 service gets the `410`. A 2.0 frame that gets `404` on any `/v2/*` route
(a still-running 1.6 service) maps it to `contract_mismatch` and shows S11's instruction: pause and resume MLX Scope in
Settings → Extensions. A folder install's running service is not restarted by an approval or a code change (SPIKES S11).

## 3. Units and naming (`src/contract/units.ts`)

The suffix carries the unit. There is no decimal GB anywhere on the wire. `panel/present/format.ts` is the only GiB formatter.

| Suffix | Meaning | Rule |
|---|---|---|
| `*Bytes` | bytes | safe integer (a unit lint enforces it); ≥ 0 except `swapDeltaBytes` |
| `*Ms` | duration in ms | ≥ 0 |
| `*At` | epoch ms, service clock | frames correct with their clock offset (median of 5 `serverNow − rtt midpoint`) |
| `*Tps` | tokens per second | ≥ 0 |
| `*Fraction` | 0…1 | never a percent |
| `*W` | watts | macmon estimate only |
| `*Tokens` | token count | integer ≥ 0 |

## 4. Basis and capabilities (`src/contract/capabilities.ts`)

```ts
export type Basis =
  | 'reported'       // the runtime, driver or kernel reported this value
  | 'derived'        // computed from reported counters (e.g. a Splash counter Δ = 1)
  | 'observed'       // Scope's own observation (e.g. a single busy llama slot's Δn_decoded/Δt)
  | 'last-observed'  // the last reading seen before the request left view (oMLX, vllm-mlx completions)
  | 'estimate';      // an estimate by its source (macmon power, runtime prefill ETA)

export type CapabilityScope = 'request' | 'server' | 'host';
export interface Capability { scope: CapabilityScope; basis: Basis }

export type CapabilityKey =
  // one active request, and the runtime reports it
  | 'request.decodeRate' | 'request.prefillRate' | 'request.prefillProgress' | 'request.prefillEta'
  | 'request.ttft' | 'request.tokens' | 'request.elapsed' | 'request.context'
  // the whole server
  | 'server.requests'          // active and queued counts: "can count requests" (attribution condition 4)
  | 'server.averages' | 'server.latency' | 'server.cache'
  | 'server.memory.process' | 'server.memory.model' | 'server.memory.metal' | 'server.memory.ceiling'
  | 'server.residency' | 'server.slots' | 'server.rates' | 'server.speculative' | 'server.catalog' | 'server.engines'
  | 'server.usage' | 'server.completions'
  // the Mac
  | 'host.cpu' | 'host.memory' | 'host.swap' | 'host.pressure' | 'host.wiredLimit'
  | 'host.gpuBusy' | 'host.gpuMemory' | 'host.thermal' | 'host.footprint' | 'host.power';

/** Absent key = not reportable on this connection. The panel shows nothing for it: no dash, no zero. */
export type Capabilities = Partial<Record<CapabilityKey, Capability>>;
```

**Honesty invariant (P3), enforced in `parseSnapshotV2` and by a test.** A non-null field implies its capability is present,
and every value the UI shows that is not `reported` carries its basis label. The field → capability map lives next to the
parser. Examples: `runtime.request.decodeTps` → `request.decodeRate`; `host.gpu.allocBytes` → `host.gpuMemory`;
`host.power.chipW` → `host.power`.

**Fixed labels from G1** (presenters, `panel/present/messages.ts`):
- `host.gpuBusy` → "GPU busy (driver-reported)". Mac card only; never a headline, score or alert.
- `host.gpuMemory` → "GPU memory (driver-reported, not model size)". ioreg Alloc failed validation (SPIKES S9): no wired-limit
  or near-GPU-limit alert uses it.
- `server.memory.model` against `host.mac.wiredLimitBytes` → "<runtime> model memory vs macOS GPU wired limit", the
  runtime's own reported allocation. It never alerts.
- `host.pressure` → "macOS memory pressure (kernel): normal / warning / critical" for levels 1 / 2 / 4. Other values are
  left out.
- `host.thermal` → "Thermal pressure (macOS)": nominal, moderate, heavy, trapping, sleeping (levels 0–4, from notifyutil).
- `host.footprint` → "<runtime> process listening on :<port>", oMLX only.
- `host.power` → "Chip power (CPU+GPU+ANE, macmon estimate) · includes all apps · not wall power". `sysW` is shown only
  when > 0.
- Never "VRAM". Ollama's `size_vram` is "GPU-resident (Ollama-reported)".

**Completion basis by runtime**

| Runtime | Completion signal | `basis` |
|---|---|---|
| Bionic / LM Studio | `Done ·` line on the `lms log stream -s server --json` stream | `reported` |
| oMLX, vllm-mlx | the request disappears from the active list | `last-observed` |
| Splash | `requests.completed` Δ = 1 with the §5.2 conditions | `derived` |
| llama-server | the only busy slot goes busy → idle | `observed` |
| Ollama, mlx-lm | none (inventory only) | — |

## 5. Reason codes (`src/contract/reasons.ts`)

Codes and params only. The English lives in `panel/present/messages.ts`. Params are allowlisted per code and never carry
free text from a runtime.

```ts
export type StatusState = 'ready' | 'degraded' | 'detecting' | 'failing' | 'unconfigured' | 'recovering';

export type StatusReason =
  | 'runtime_unreachable'      // failing · {port, sinceAt}
  | 'authentication_failed'    // failing
  | 'configuration_missing'    // unconfigured
  | 'unsupported_runtime'      // unconfigured
  | 'unsupported_contract'     // degraded; 3× in a row triggers re-detection
  | 'detecting' | 'redetecting'// detecting
  | 'runtime_changed'          // degraded · {detected: RuntimeKind} → "Looks like Splash now · Switch" (explicit runtimes never auto-switch)
  | 'loading'                  // degraded · llama-server /health 503
  | 'recovering'               // recovering · Splash transport.recovering · {retryInMs, crashTrace: boolean}
  | 'status_stale'             // degraded · Splash transport.status_stale
  | 'not_admitting'            // degraded · Splash metal.healthy !== true or memory_pressure 'critical'
  | 'admin_unauthorized'       // degraded · oMLX admin 401/403 → /api/status fallback, server coverage
  | 'lms_unavailable'          // degraded · no {"lmstudio":true} greeting in 10 s: no lms spawn
  | 'metrics_required'         // degraded · sleep-capable llama-server without usable /metrics: no live slots
  | 'sleeping';                // ready · llama-server is_sleeping: /slots and /metrics are not polled

/** Panel-side only; never sent by the service. */
export type FrameReason =
  | 'contract_mismatch'        // 404 on /v2/* or 410 on /snapshot
  | 'needs_approval'           // NO_SERVICE after an update changed the permission set (SPIKES S11)
  | 'service_failed' | 'host_unavailable' | 'host_timeout' | 'host_disconnected' | 'host_rejected';

/** Why an item stays "Server-wide" (plan §5.5). One reason per item. */
export type WithholdReason =
  | 'projects-loading' | 'projects-error' | 'too-many-projects'
  | 'several-chats' | 'subagent-running'
  | 'other-provider'           // "This chat uses Splash · Watch Splash"
  | 'model-differs' | 'model-unknown'
  | 'cannot-count' | 'overlap' | 'outside-turn' | 'joined-mid-turn' | 'not-observed'
  | 'auto-off';

export type AlertId =
  | 'runtime-lost' | 'model-unloaded'
  | 'pressure-warning' | 'pressure-critical' | 'swap-growth' | 'thermal'
  | 'splash-recovering' | 'omlx-prefill-stall' | 'omlx-memory-guard';
// Removed at G1: 'near-gpu-limit' (ioreg Alloc not validated). There is never an alert on GPU utilisation.
// 'slower-than-usual' is a panel-side regression flag (§5.6), not a service alert.

export type ReasonParams = Record<string, string | number | boolean>;
```

## 6. Types

### 6.1 `SnapshotV2` (`src/contract/snapshot.ts`)

```ts
export type RuntimeKind = 'omlx' | 'lmstudio' | 'splash' | 'vllm-mlx' | 'mlx-lm' | 'llama-server' | 'ollama';
export type Surface = 'panel' | 'page' | 'status' | 'background';
export type Phase = 'idle' | 'queued' | 'prefill' | 'decode' | 'processing' | 'loading' | 'not-loaded' | 'unknown';

export interface SnapshotV2 {
  contractVersion: 2;
  serverNow: number;                         // At
  service: { version: string; instance: string };   // instance: 8 hex, random per service start
  connection: ConnectionV2;
  status: { state: StatusState; reason: StatusReason | null; params: ReasonParams; sinceAt?: number };
  capabilities: Capabilities;
  runtime: RuntimeV2;
  host: HostV2;
  completions: CompletionsV2;
  marksHead: number;                         // newest turn-mark seq in the 64-entry ring; 0 when empty
  alerts: AlertV2[];
  alertLog: AlertLogEntryV2[];               // ≤ 20, newest first, service memory only
  lease: LeaseV2;
  nextPollMs: number;
}

export interface ConnectionV2 {
  id: string;                                // connection id, [A-Za-z0-9._-]{1,64}
  label: string;
  runtime: RuntimeKind | null;
  version?: string;                          // runtime version when reported, e.g. '0.7.0rc1'
  engine?: 'splash' | null;                  // 1.6 meaning: an LM Studio-compatible host serving Splash models
  host?: 'bionic' | null;
  generation: number;                        // +1 on connection change, re-detection, or an LM Studio /api/v0/models state change
  choices: Array<{ id: string; label: string; runtime: RuntimeKind | null }>;   // ≤ 8
  detection: {
    basis: 'explicit' | 'hint' | 'probe';
    confidence: 'high' | 'medium' | 'low';
    probe?: '/health' | '/props' | '/api/version' | '/lmstudio-greeting' | '/status' | '/v1/models';
  };
}

export interface RuntimeV2 {
  phase: Phase;
  request: RequestV2 | null;                 // null unless exactly one request is active and the runtime reports it
  server: {
    active: number | null;                   // null = cannot count requests
    queued: number | null;
    averages?: { decodeTps?: number; prefillTps?: number; cacheEfficiencyFraction?: number;
                 requestsTotal?: number; failedTotal?: number; uptimeMs?: number };
    histograms?: { ttftMs?: Quantiles; itlMs?: Quantiles };   // Splash native metrics (G1: p50/p95, no /metrics)
    cache?: { ramBytes?: number; ssdBytes?: number; ramEntries?: number; ssdEntries?: number; lastLookup?: 'hit' | 'miss' };
    speculative?: { draftedTokens: number; acceptedTokens: number; acceptanceFraction: number; windowMs: number };
    rates?: { promptTps?: number; decodeTps?: number; windowMs: number };  // llama-server *_total deltas, never the windowed gauges
  };
  memory: { processBytes?: number; modelBytes?: number; metalBytes?: number; metalPeakBytes?: number; ceilingBytes?: number };
  residency: ResidencyV2[];                  // ≤ 12
  slots: SlotV2[];                           // ≤ 16, llama-server numeric allowlist
  catalog: CatalogV2[];                      // ≤ 12
  engines: EngineV2[];                       // ≤ 8, detail=server only (lms runtime ls, cached 10 min)
}

export interface RequestV2 {
  model: string | null;
  decodeTps?: number; prefillTps?: number;
  prefillProcessedTokens?: number; prefillTotalTokens?: number; prefillFraction?: number; prefillStale?: boolean;
  prefillEtaMs?: number;                     // runtime estimate; only while prefill is live and fraction < 1
  promptTokens?: number; cachedTokens?: number; outputTokens?: number;
  elapsedMs?: number; ttftMs?: number;
  contextWindowTokens?: number; contextUsedTokens?: number;   // prompt + output against the model limit
}

export interface Quantiles { p50: number; p95: number; n: number; window: 'native-last-4096' }

export interface ResidencyV2 {
  model: string;
  phase: Phase;
  source: 'runtime' | 'lms-ps' | 'ollama-ps';
  active?: number; queued?: number;
  bytes?: number;                            // runtime-reported allocation or Ollama size
  gpuResidentBytes?: number;                 // Ollama size_vram: "GPU-resident (Ollama-reported)"
  unloadsAt?: number;                        // Ollama expires_at: "unloads in"
  contextWindowTokens?: number;
  decodeTps?: number; prefillFraction?: number;
}

export interface SlotV2 {                    // llama-server /slots, numeric allowlist only (S7b)
  id: number; busy: boolean; contextWindowTokens: number;
  decodedTokens?: number; remainingTokens?: number; promptTokens?: number;
  decodeTps?: number;                        // observed, and only while exactly one slot is busy
}

export interface CatalogV2 {
  name: string; format: 'mlx' | 'gguf' | 'splash' | null; loaded: boolean | null; contextWindowTokens: number | null;
  vision?: boolean; inputModalities?: Array<'text' | 'image' | 'audio'>;   // Splash 1.1 chips
}

export interface EngineV2 { name: string; version: string; selected: boolean }

export interface HostV2 {
  sampledAt: number;
  cpuFraction: number;
  memTotalBytes: number;
  memUsedBytes: number;                      // physical minus free; includes reclaimable pages (1.6 meaning)
  mac?: { sampledAt: number; pressureLevel: 1 | 2 | 4; wiredLimitBytes?: number;
          swapUsedBytes: number; swapTotalBytes?: number; wiredBytes?: number; compressedBytes?: number };
  gpu?: { sampledAt: number; busyFraction?: number; allocBytes?: number; inUseBytes?: number };   // ioreg, driver-reported
  thermal?: { sampledAt: number; level: 0 | 1 | 2 | 3 | 4 };    // notifyutil com.apple.system.thermalpressurelevel
  runtimeProcess?: { sampledAt: number; runtime: 'omlx'; port: number; footprintBytes: number };   // never a PID
  power?: { sampledAt: number; field: 'all_power'; chipW: number; cpuW?: number; gpuW?: number; aneW?: number;
            sysW?: number; coverageFraction: number };   // macmon; absent without macmon (Scope never installs it)
}

export interface CompletionsV2 {
  instance: string;                          // = service.instance; a change means the ring restarted
  cursor: number;                            // newest seq in the ring
  reset: boolean;                            // `since` was from another instance or fell off the ring: the ledger records a gap
  items: CompletionV2[];                     // seq > since, oldest first, ≤ 64 per response
}

export interface AlertV2 {
  id: AlertId; severity: 'info' | 'warning' | 'critical'; since: number; params: ReasonParams;
  badge: boolean;
  toastSeq?: number;                         // present only for the leader; toast once per new value
}
export interface AlertLogEntryV2 { id: AlertId; severity: 'info' | 'warning' | 'critical'; since: number; until: number | null; params: ReasonParams }

export interface LeaseV2 {
  leader: boolean;                           // this frame is the one side-effect frame (P9)
  epoch: number;                             // +1 on every handover
  ttlMs: number;                             // 12,000
  leaderSurface: 'page' | 'panel' | 'status' | null;
}
```

### 6.2 `CompletionV2` (`src/contract/completion.ts`)

```ts
export interface CompletionV2 {
  seq: number;                               // monotonic per service instance
  finishedAt: number;
  startedAt: number | null;
  model: string | null;
  basis: Basis;                              // per the §4 runtime table
  promptTokens?: number; cachedTokens?: number; outputTokens?: number;
  ttftMs?: number; prefillMs?: number; decodeTps?: number; prefillTps?: number;
  overlapped: boolean;                       // another request was active at any sample in its span
  aggregateOf?: number;                      // > 1 when one counter step covered several requests
  verdict?: { attr: 'inferred' | 'withheld' | 'armed'; reason?: WithholdReason; at: number };
  host: {
    pressureMax?: 1 | 2 | 4;
    swapDeltaBytes?: number;                 // signed
    gpuAllocMaxBytes?: number;               // driver-reported; a co-factor only, never an alert
    thermalMaxLevel?: 0 | 1 | 2 | 3 | 4;
    energyJ?: number;                        // macmon estimate, only with powerCoverage ≥ 0.8
    powerCoverage?: number;
  };
}
```

Rows with no `verdict` are "Server-wide · not observed". Baselines exclude `aggregateOf`, `overlapped` (per-request
metrics), `estimate`, gap rows, and `last-observed` rows for TTFT and token statistics (§5.6).

### 6.3 `TrendV2` (`src/contract/trend.ts`)

```ts
export type TrendSeries = 'decodeTps' | 'prefillTps' | 'active' | 'cpuFraction' | 'memUsedBytes'
  | 'swapUsedBytes' | 'pressureLevel' | 'gpuBusyFraction' | 'chipW';

export interface TrendV2 {
  contractVersion: 2;
  serverNow: number;
  windowMs: 900_000 | 1_800_000 | 3_600_000;
  bucketMs: number;                          // windowMs / 180
  startAt: number;
  series: Partial<Record<TrendSeries, { basis: Basis; buckets: Array<[min: number, max: number, last: number] | null> }>>;
  gaps: Array<{ fromAt: number; toAt: number }>;   // "Not observed · Scope wasn't open"; never interpolated
  marks: Array<{ seq: number; at: number; phase: 'started' | 'completed' | 'failure' }>;   // no tags on the wire
}
```

The ring holds 2 s buckets × 1,800 (60 min) per slot, filled only by view-driven reads. A gap longer than 2.5× the cadence
is a segment break. `series` is a comma list from the `TrendSeries` allowlist (default `decodeTps`).

## 7. Query parameters

| Param | Routes | Grammar | Meaning |
|---|---|---|---|
| `provider` | all | `[A-Za-z0-9._-]{1,64}` | connection id |
| `runtime` | all | `RuntimeKind` | explicit runtime; never auto-switched |
| `frame` | snapshot | `[0-9a-f]{8}` | random per frame mount, memory only; lease key |
| `surface` | snapshot | `Surface` | lease priority page 3 > panel 2 > status 1; `background` is never eligible |
| `tier` | snapshot | `glance\|full` | probe tier (§8). status and background use `glance` |
| `since` | snapshot | integer ≥ 0 | completion cursor; items with `seq > since` |
| `mark` | snapshot | `<started\|completed\|failure>.<atMs>.<tag8>` | turn marker; ≤ 4 per request |
| `attr` | snapshot | `<seq>.<inferred\|withheld\|armed>.<reason\|->` | the frame's verdict for a completion; ≤ 8 per request |
| `detail` | snapshot | `server` | gates Server-tab-only reads (`lms runtime ls`, catalog refresh). Requires `tier=full` |
| `window` | trend | `900\|1800\|3600` | seconds |
| `series` | trend | comma list of `TrendSeries` | default `decodeTps` |
| `range` | usage | `7d\|30d\|90d` | |

**Marks.** `tag8` is a pure-JS hash (`src/contract/hash.ts`; `crypto.subtle` is not guaranteed) of the session id salted
with `service.instance`. It lives in service memory only and is never echoed. The service dedupes marks by
`(tag, phase, |Δat| ≤ 1 s)` into a ring of 64. Lifecycle replays (×3 on mount, SPIKES S2) never produce a mark.

**Verdicts.** `attr=` records a visible frame's attribution verdict next to its completion, so any later leader writes the
same ledger label. Example: `attr=58.withheld.several-chats`.

**Validation.** Unknown parameters are ignored; malformed known parameters → `400 bad_query`. No parameter value is ever
logged or echoed.

## 8. Cadence, tiers and `nextPollMs`

| Surface | Active | Idle | Notes |
|---|---|---|---|
| panel, page | 500 ms | 2 s | Energy-saving floor 3 s (applied by the frame) |
| status | 1 s | 3 s, then 10 s after 5 min idle | Energy-saving floor 5 s |
| any non-leader while a higher-priority leader is visible | ≥ 10 s | ≥ 10 s | |
| backoff (one, in the scheduler) | `min(8 s, 0.5 s · 2ⁿ)` | | |

Splash while `transport.recovering`: runtime reads are cached for 30 s (SPIKES S7), so Scope does not add to the server's
restart retries. Host readings keep their own cadence.

**Probe tiers** (every exec: absolute path, no shell, validated argv)

| Probe | full (panel/page) idle / active | glance (status) |
|---|---|---|
| `vm_stat` + `sysctl -i vm.swapusage kern.memorystatus_vm_pressure_level iogpu.wired_limit_mb` | 10 s | 10 s |
| `ioreg -r -d 1 -w 0 -c IOAccelerator` (128 KiB cap) | 15 s / 5 s | 15 s |
| `notifyutil -g com.apple.system.thermalpressurelevel` | 60 s | 60 s |
| `lsof -nP -iTCP:<port> -sTCP:LISTEN -t` (oMLX listener only) | generation change + 120 s | — |
| `footprint -p <pid>` (oMLX only; PID start time re-checked first) | 30 s / 10 s | — |
| `lms ps --json --port <internal>` | generation change (`/api/v0/models` state) + 180 s | — |
| `lms runtime ls --port <internal>` | Server tab visible (`detail=server`), cached 10 min | — |
| `macmon pipe -i 1000` | streamed, 60 s idle-stop | — |
| **Spawns/min** | **≤ 24 idle / ≤ 36 active** | **≤ 18** |

Runtime reads under G1: oMLX never calls `/admin/api/stats`; Splash reads `/status` only; llama-server follows the S7b rule
(`/slots` only while `/metrics` shows `requests_processing ≥ 1` on sleep-capable builds, `*_total` deltas only).

## 9. Privacy on the wire

**Never on the wire (class A, tested with canaries):** PIDs, `api_key`, cookies, prompt or response text, file paths
(llama `model_path` keeps only its last segment), session IDs, session titles, project names and folders, request IDs,
`tag8`, Splash `transport.last_crash_trace` and `transport.error` text (presence as a boolean param only), Splash
`instance.*` and `identity.*`, llama `generation_prompt`, usernames.

**Model names (class B)** may appear in `/v2/snapshot`, `/v2/usage`, the in-view DOM and the local ledger. They are forbidden
in Copy, compose, `/scope` text, toasts, the baseline summary, `capture.v2` and receipts. `panel/share/report.ts` is the one
sanitizer.

## 10. Changes from plan §4.2, for owner review

1. **Thermal.** `CompletionV2.host.thermalWarning` (pmset) becomes `thermalMaxLevel` 0–4 (notifyutil), per G1.
2. **No GPU-limit alert.** `near-gpu-limit` is dropped from `AlertId`; `gpuAllocMaxBytes` stays as a co-factor only.
3. **Splash latency.** `server.histograms` carries native `ttft_ms` / `itl_ms` p50/**p95** with n (plan said p90), from
   `/status`; there is no `/metrics` read.
4. **`attr` accepts `armed`.** An armed result from a non-leader frame must reach the leader's ledger with the same label.
5. **`connection.generation` is a counter** (1.6 used an opaque string), and `connection.version` is added for the Server
   runtime card.
6. **`lease.leaderSurface`** is added so a non-leader frame can say which surface is recording.
7. **llama-server** gains `server.rates` (from `*_total` deltas) and `speculative`; the exact series names are confirmed
