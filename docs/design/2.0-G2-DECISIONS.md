# MLX Scope 2.0 · G2 design decisions

**Reviewed:** the mock `docs/design/2.0-mock.html` at `fda3e87`: 106 screenshots in `2.0-mock-shots/` and 452 checked frames.

**Authority:** the owner delegated design authority for this run ("full permission to execute the plan"). These decisions are listed so the owner can review and override them.

## Approved
- **Visual system:** the mock evolves the 1.6 tokens, card, hero and segmented tabs, so there is no new visual language. Stage 8 implements it as shown.
- **Work Status section**
  - Glance line at 56 px, 80 px with an alert, and 24 px for a non-local chat.
  - The **Turn stats replacement** view (owner decision 13) at ≤200 px has these rows:
    - Response
    - Turn time
    - Model · tool time
    - First TTFT
    - Tokens in · out
    - Cache %
    - Context used
    - vs usual
  - Basis is shown as a muted suffix on non-reported rows only.
  - A row a runtime can't report is left out (for example First TTFT on oMLX).
  - A withheld turn shows its server-wide reason instead of a turn summary.
  - A one-time dismissible tip reads: "Replace Turn stats: hide it in Panel sections and drag MLX Scope into its place".
- **`--scope-bad`:** accepted. It is derived from the host's own error token, used only for critical states (runtime lost, pressure critical), and turns 1.6's offline dot from amber to red.
- **Mac card labels:** use the **short labels** from `decision-short-labels-dark-320.png`.
  - "GPU memory · driver-reported" and "Chip power · estimate" keep the basis visible.
  - The full fixed wording from SPIKES S9 lives in the section ⓘ: "not model size"; "CPU+GPU+ANE, macmon estimate · includes all apps · not wall power".
- **Energy unit:** "tok/J", with an ⓘ explaining "tokens per joule = tok/s per W; chip estimate".
- **Percentiles:** baselines use p50/p90 with n. Splash native latency uses the runtime's own p50/p95.
- **Thermal:** warn from macOS thermal pressure level 2 ("Heavy"). The raw level name is shown only in the ⓘ.
- **Trend gaps and idle:** idle buckets are gaps, never zero, and "Not observed" is hatched. Charts appear after ≥2 samples.

## Noted for the owner
Hiding the host's **Turn stats** in Panel sections hides it for **every** chat, including cloud chats. For a cloud chat, MLX Scope's section collapses to a 24 px "Chat uses a non-local model" line, so cloud chats lose the host's per-turn speed while the swap is active. The tip's ⓘ says so.
