# 5.5.0 local verification

Status: local source, package and browser checks passed; not published. Hosted CI and publication were not run. Push, PR,
merge and tag each remain subject to fresh approval.

## Outcome

- 5.5.0 combines Splash admission waits, DFlash2 draft acceptance and the memory-room view with Memory thief, the
  Engine room and advisory trial verdicts.
- While Splash reports a memory wait or short room, the Engine room identifies the largest local app footprints. A
  recorded wait keeps up to three app names and footprints in local History; the share paths exclude app names. Session
  titles appear only beside live lanes while Engine room is open and are not saved.
- Trial boundaries detect observed Splash model, context-window and memory-plan changes; users can also start a boundary
  manually. History compares waits, decode batches and solo long replies with an earlier local History stretch or
  device-local baseline notes. Verdicts are advisory and never change runtime settings. No observed overlap is unknown,
  not a pass.
- Existing reply and turn tuple formats and `LEDGER_SCHEMA` remain unchanged. `/usr/bin/top` is the only new executable
  permission, used for a bounded local app-memory sample.
- The panel bundle is 280,773 bytes. Its packaging ceiling is now 295,000 bytes, preserving the project's existing
  approximately 5% measured headroom; this is a packaging check, not a runtime CPU or memory budget.

## Completed checks

- `bun run check` passed: type-check; privacy scan (693 files); 1,886 Bun tests across 139 files; 81 companion tests;
  15 ComfyUI helper tests; rebuilt panel/service bundles; and package verification including the manifest/permission
  match, bundle ceilings, CSP/leak checks, reproducible ZIP, extracted-file equality and packaged-service smoke.
- The browser suite passed all 638 Chromium/WebKit cases (319 per engine) with two workers. It includes the trial card at
  phone and desktop widths, in both themes; local baseline notes and manual trial start were exercised in the fixture.
- The History browser cases and trial unit tests passed; `git diff --check` was clean.

## Limits

- No model was loaded or switched, and no two-chat inference test was run. The approved read-only Splash `/status` read
  was completed, but its body was not saved or run through the adapter. Trial boundaries, wait comparisons and
  concurrent-batch verdict behavior were verified with synthetic fixtures, not live model runs.
- The UI/browser checks use the synthetic fixture host, not an installed OpenChamber release. Visual goldens and a live
  app update were not run. No hosted CI, push, PR, merge, publish or tag is part of this local qualification.
- A one-worker `check:all` run reached the browser phase, then hit the shell's 10-minute limit after 101 Chromium cases
  with no assertion failures. The complete browser phase was then run separately with two workers and passed all 638
  cases.
