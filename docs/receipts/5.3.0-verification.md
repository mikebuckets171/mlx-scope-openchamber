# 5.3.0 compatibility verification

Status: all local acceptance checks pass. Publication waits for hosted CI; installation verification follows the release.

## Outcome

- Companion 3.6.0 accepts every OpenCode 2 release from 2.0.25, retaining the per-feature runtime checks and rejecting
  a new major or unreviewed suffixed build.
- Scope updates an enabled, unchanged helper it owns once at service startup; manual, edited and disabled installs
  remain untouched. The updater uses the existing lock, config-conflict detection, file renames and rollback.
- Model labels come from the selected provider's OpenCode configuration. Runtime IDs, attribution and stored History
  retain their identities. Display names are bounded and model paths are reduced to names before leaving the service.
- The unpublished llama-swap/Splash prefill matching fix is included; the previously installed patched bundle matched
  that fix byte for byte before this work.
- The Session section keeps its frame by the user's decision: replacing it with a host-drawn section would stop
  History recording, alert toasts and slower-than-usual calculations when no Scope panel was open.
- Playwright is updated from 1.61.0 to stable 1.64.1 at the user's request. It uses the already installed Chromium
  revision 1248 and WebKit revision 2370; no browser cache was replaced or deleted.

## Completed checks

- Baseline `bun run check` passed before implementation, including the prefill fix.
- The final full implementation check passed: type checking, privacy scan (679 files), 1,842 Bun tests, 81 companion
  tests, 15 ComfyUI helper tests, rebuilt bundles, reproducible ZIP and extracted-package smoke checks. Review added
  checks for an update queued after Disable, failed-update rollback/no retry, configuration name refresh, path
  sanitization and provider-prefix matching; these pass as part of that full run.
- All 624 Chromium/WebKit cases passed on Playwright 1.64.1 against the final rebuilt bundles, with two workers
  (312 per engine). The 10 focused compatibility/name cases also passed separately, including the four newly added
  cases. The earlier 620-case run with one worker passed before the final review changes.
- Presentation goldens: 21 pass with strict zero-pixel tolerance after regeneration. All 33 changed images were
  visually reviewed against the previous baselines: differences are confined to native dropdown controls, and on the
  storage screen the adjacent native buttons. Dimensions, layout and every text golden are unchanged. The regenerated
  files were also compared pixel-for-pixel with the reviewed actual renders. Image count/size budgets pass.
- Against the OpenCode 2.2.0 binary bundled with OpenChamber 2.5.3, all five isolated native synthetic-provider runs
  passed: local HTTP with advancing prompt progress, synthetic-remote HTTP, WebSocket reuse/tool continuations/cancel,
  helper hot reload from 3.5.0, and compaction followed by a measured resumed step. No real inference or live config
  changes were involved. Evidence: [companion-3.6.0.json](companion-3.6.0.json).
- A read-only check of the already running Splash backend confirmed its native model ID differs from the llama-swap
  route only by the quantization suffix, which the display-name lookup handles. No model was loaded or switched.

## Remaining acceptance checks

- PR CI, merge and the tagged release workflow; verify the release branch/package.
- Install through OpenChamber's Git-update UI without losing the existing prefill fix or History. Verify helper 3.6.0
  loads automatically on 2.2.0, short names and an ordinary chat reading; record setup notes.

## Limits

The initial browser attempts did not execute product code: the pinned 1.61.0 browsers were missing. These are not
counted as product test failures or passes. Current browser checks use 1.64.1 instead.

No model benchmark, service restart, inference configuration change or overhead experiment is part of this release.
Polling, telemetry processing and storage limits are unchanged. The startup helper update is a bounded one-time setup
operation; the 5.2.0 overhead receipt remains the prior steady-state evidence, not a new 5.3 measurement. Real local
prefill verification remains for the next ordinary local reply; synthetic native fixtures cover advancing counters.
